# Cobb 500 expected live-weight reference

The expected-weight curve implemented in this project is based on the **Cobb500 Broiler Performance & Nutrition Supplement**, using the metric performance objectives for an as-hatched flock. It is a planning reference rather than a production guarantee; actual performance varies with sex, strain, flock health, feed formulation, ventilation, temperature, stocking density, and management.
