# BroilFarm Enterprise ERP 🐔📊
### المنظومة المؤسسية السحابية الشاملة لإدارة مزارع دواجن التسمين بنظام البطاريات (SaaS)

منصة **BroilFarm Enterprise ERP** هي نظام متكامل من فئة **Poultry Farm ERP / Farm Management SaaS** مخصص للشركات ومزارع دواجن التسمين الكبيرة والمتوسطة، ومصمم خصيصاً لتلبية متطلبات السوق المصري وتحديات الإنتاج الداجني بنظام البطاريات المغلقة.

---

## 🌟 أبرز مميزات وإمكانيات المنظومة (Core Capabilities)

### 1. 🏢 إدارة التعددية المؤسسية (Multi-Tenancy & Company Engine)
- دعم كامل للشركات المتعددة (Multi-Company) والمزارع المتعددة (Multi-Farm) مع عزل بيانات تام على مستوى قاعدة البيانات واستعلامات الـ ORM.
- مستويات اشتراك سحابية مرنة (Free, Starter, Pro, Business, Enterprise) مع فحص آلي لحدود المزارع والعنابر والمستخدمين.

### 2. 🛡️ نظام الصلاحيات والأمان المتقدم (Granular RBAC & Security)
- **8 أدوار وظيفية قياسية**:
  - مالك المؤسسة (Owner)
  - مدير عام المؤسسة (General Manager)
  - مدير مزرعة (Farm Manager)
  - طبيب بيطري (Veterinarian)
  - مهندس إنتاج (Engineer)
  - مشرف عنابر (Supervisor)
  - محاسب مالي (Accountant)
  - عامل تشغيل (Worker)
- توثيق محلي مستقل بكلمات مرور مشفرة بـ `scrypt` وجلسات JWT آمنة.
- حماية متقدمة من هجمات DoS ومحاولات التخمين عبر **Sliding-Window Rate Limiter**.
- عزل كامل لملفات تعريف الارتباط مع سياسة `SameSite: Lax` لحماية الجلسات المستقلة من هجمات CSRF.

### 3. 🧬 محرك ذكاء الإنتاج والتحليلات البيولوجية (Production Intelligence)
- **حاسبة معامل التجانس (CV% & Uniformity)**: تحليل تباين أوزان الطيور، حساب الانحراف المعياري، وحساب نسبة الطيور ضمن نطاق $\pm 10\%$ مع تقييم جودة القطيع (عالمي، ممتاز، جيد، ضعيف).
- **كتالوجات معايير السلالات العالمية (Ross 308 & Cobb 500)**: رسم بياني تفاعلي يقارن التطور اليومي للوزن الفعلي للمزرعة بالمنحنى القياسي للكتالوج.
- **مؤشر استهلاك المياه إلى العلف (Water:Feed Ratio)**: تقييم ذكي ومعدل حسب درجات الحرارة لكشف تسريبات خطوط المياه أو الإصابات المعوية والإسهالات مبكراً.
- **معامل الكفاءة الأوروبي (EPEF / EEI)** و **معامل التحويل القياسي المعدل لوزن 2.0 كجم (Adjusted FCR)**.

### 4. 💰 محرك التكاليف وتحليل نقطة التعادل (Financial Costing & Break-Even)
- حساب تكلفة الكيلو القائم وتكلفة الطائر التلقائية من واقع سجلات المصروفات الفعلية.
- تفصيل التكاليف حسب البنود الـ 9 (كتاكيت، أعلاف، أدوية، طاقة وغاز، عمالة، صيانة، شحن، معدات، أخرى).
- **حساب سعر نقطة التعادل (Break-Even Price EGP/kg)** والكتلة الحيوية المطلوبة لتغطية التكاليف وهامش الأمان السعري.
- حساب هوامش الأرباح الحقيقية، صافي الدخل، والعائد على الاستثمار (ROI %).

### 5. 🌾 إدارة المخازن والربط الآلي للأعلاف والأدوية (Inventory & Auto-Sync)
- خصم أوتوماتيكي دقيق لاستهلاك العلف اليومي من رصيد الشكاير بالمخزن فور تسجيل اليومية.
- حساب استهلاك العلف اليومي المتوقع ديناميكياً بناءً على حجم وعمر وسلالة القطيع النشط.
- حساب أيام التغطية المتبقية (Days of Cover) وتنبيهات إعادة الطلب التلقائية.
- إدارة الموردين وأوامر الشراء والحسابات المستحقة.

### 6. ⚖️ كونسول بيع التجار وربط الموازين الذكية (Trader Sales Console & Smart Scale)
- تسجيل دفعات الوزن اللحظي بدقة (الوزن الفارغ Tare / الوزن القائم Gross / الوزن الصافي Net).
- دعم استقبال وقراءة تدفقات أجهزة الوزن والموازين الرقمية عبر Serial و Bluetooth.
- تسوية حسابات التجار ومتابعة الدفعات النقدية والتحويلات البنكية والآجل.

### 7. 👥 إدارة حسابات العمالة والرواتب (Workforce Ledger)
- سجل مالي متكامل لكل عامل لحساب الراتب الشهري، السلف، المسحوبات، والمكافآت مع أرصدة فورية.

### 8. 📡 الحساسات البيئية والتليمترية (IoT Sensor Telemetry)
- استقبال واستعراض قراءات الحرارة، الرطوبة، الأمونيا ($NH_3$)، ثاني أكسيد الكربون ($CO_2$)، وسرعة الهواء مع تقييم لحظي لسلامة بيئة العنبر.

### 9. 📈 محاكي الربحية وتحديد موعد الذبح الأمثل (Profitability Simulator)
- محاكاة سيناريوهات "What-If" اليومية للتنبؤ بأفضل يوم للبيع والتسويق لتحقيق أقصى هامش ربح قبل تدهور معامل التحويل.

### 10. 📊 المقارنة التحليلية بين الدورات (Multi-Cycle Benchmarking)
- مقارنة أداء الدورات جنباً إلى جنب مع تحديد الدورة الأعلى كفاءة والأقل تحويلاً والأكثر ربحية.

## 🛠️ البنية البرمجية والتقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, TailwindCSS v4, Recharts, Wouter, Radix UI, Lucide Icons, Sonner.
- **State & Data Fetching**: tRPC v11, TanStack React Query, React.lazy Code-Splitting.
- **Backend**: Node.js (ESM), Express, tRPC Server Adapters, Jose (JWT), Scrypt Password Hashing.
- **Database & ORM**: Drizzle ORM, MySQL / PostgreSQL compatible.
- **Security & Reliability**: In-memory Sliding Window Rate Limiter, Strict Env Validation, Role-Based Access Control.
- **Containerization**: Multi-stage Production Dockerfile (`node:20-alpine`).

## 🚀 تشغيل المنصة (Getting Started)

### 1. المتغيرات البيئية (`.env`)
أنشئ ملف `.env` في المجلد الرئيسي للمشروع:
```env
PORT=3000
NODE_ENV=production
DATABASE_URL=mysql://user:password@localhost:3306/broilfarm
JWT_SECRET=your_super_secret_jwt_key_at_least_16_chars_long
```

### 2. التشغيل عبر Docker (موصى به للإنتاج)
```bash
# بناء الصورة وتشغيل الحاوية
docker build -t broilfarm-erp .
docker run -d -p 3000:3000 --env-file .env --name broilfarm broilfarm-erp
```

### 3. التشغيل المباشر عبر Node.js
```bash
# تثبيت الاعتماديات
npm install

# بناء الواجهة والخادم
npm run build

# تشغيل الخادم
npm start
```

### 4. تشغيل الاختبارات
```bash
# تشغيل كامل حزمة اختبارات المنظومة
npx vitest run
```
