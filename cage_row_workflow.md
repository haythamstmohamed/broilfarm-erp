# Cycle-linked cage-row workflow

The housing workspace now displays only houses assigned to the selected active cycle. For Farm غرب / Cycle أغسطس, the verified house list is الكبير (12,500 birds), الحضانة (4,500 birds), and قبلي (6,500 birds).

The **إضافة صف أقفاص** form restricts its house selector to exactly those three assigned houses. It collects the row label, the number of cages in the row, and the number of chicks per cage. Saving a row is protected against exceeding the assigned-house or physical-house capacity. Per-row feed forecasts use the selected cycle day and present kilograms, buckets, and bags on the dashboard, using four buckets per bag.

The dashboard empty state was verified for the current real-data workspace. It now explains that a cage row must be added from the housing page before per-row estimates are displayed, while retaining the existing house-level projections for all assigned houses.
